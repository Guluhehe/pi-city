# Pi 英雄角色资产：正式生产简报

## 资产目标

Pi 必须从“功能球体”升级为玩家在近景中愿意信任的**城市助手角色**。它的角色职责不是吉祥物装饰，而是把“观察—带回证据—改变下一步”表达为可读动作。这个资产首先服务第二章“记忆风”，随后复用至全部章节。

> 视觉验收并不以“更精细”作为标准，而以固定英雄镜头中是否一眼看懂：Pi 是谁、在看什么、准备替谁去办什么事。

## 身份锚点与不可变特征

| 维度 | 必须保留的特征 | 禁止项 |
|---|---|---|
| 轮廓 | 短、稳、略前倾的助手体态；圆润深青主体；两只短腿；可见手臂。 | 无肢体的纯球、过高或过瘦的人形。 |
| 工作身份 | 提灯帽、双肩包、可取出的纸页/便签、小铜扣。 | 武器、盔甲、赛博接口、夸张法杖。 |
| 表情 | 两枚柔和暖光眼睛；无嘴或极弱嘴形，靠头部朝向表达注意。 | 强人脸化、恐怖空洞眼、过度拟真皮肤。 |
| 材质 | 深青漆面主体；棕皮革双肩包；磨损铜帽灯/扣件；暖色玻璃；纸页。 | 统一塑料粗糙度、纯色无层次、强自发光躯干。 |
| 比例 | 帽顶到脚底约 1.7–1.9 个“身体球”高；头灯和背包形成非对称剪影。 | 正圆对称球体、只有光环而缺少实体部件。 |

## 可建模部件清单

| 编号 | 部件 | 交付类型 | 材质槽 | 备注 |
|---|---|---|---|---|
| P01 | 深青主体 | 主网格 | `pi_painted_teal` | 哑光漆面，腰部有轻微收束。 |
| P02 | 帽灯与帽檐 | 独立网格 | `pi_brass`、`pi_warm_glass` | 必须可在轮廓中与头部区分。 |
| P03 | 双肩包与肩带 | 独立网格 | `pi_leather`、`pi_brass` | 左右不完全对称，至少有一枚可见铜扣。 |
| P04 | 手臂与手套/短手 | 独立网格 | `pi_painted_teal`、`pi_leather` | 支持取纸、指向和小跑。 |
| P05 | 短腿与鞋底 | 独立网格 | `pi_painted_teal`、`pi_leather` | 脚底需支持湿石地面的接触阴影。 |
| P06 | 纸页/便签 | 独立附属网格 | `pi_paper` | 可在 `take-note` 动画中显露。 |

## 技术预算与GLB规则

| 项目 | 交付标准 |
|---|---|
| 格式 | `pi-hero.glb`，GLB 2.0。 |
| 网格预算 | 3,000–8,000 三角面；不以低面数牺牲近景轮廓。 |
| 材质 | 最多 5 个共享PBR材质槽；每类材质具备 BaseColor、Normal、Roughness，金属件另有 Metallic。 |
| UV | 无重叠主UV；皮革、铜、纸页允许独立局部UV岛。 |
| 骨架 | 单一主骨架；根节点为 `Armature`；无缩放动画。 |
| 轴向与尺度 | Y向上，面向 -Z；身高约 1.25m；脚底位于世界原点。 |
| 动画采样 | 30fps；循环标记正确；单段单独命名并打包在同一GLB。 |

## 三段强制动画

| 动画片段名 | 时长建议 | 可读动作 | 运行时触发 | 验收标准 |
|---|---:|---|---|---|
| `idle-observe` | 2.0–3.5秒循环 | 微呼吸、帽灯轻摆、眼睛和头部先看玩家再转向异常。 | 抵达/观察。 | 静音播放时仍看出“它注意到一件事”。 |
| `take-note` | 1.2–1.8秒 | 从双肩包取出纸页，抬到胸前确认，再收回。 | Pi 带回新线索。 | 纸页、手和背包的因果关系清楚，无穿模。 |
| `turn-and-trot` | 1.5–2.5秒 | 先确认目标方向，转身两至三步小跑后停住。 | 新发现改变下一步。 | 身体重心、脚步和前进方向一致，可接任意路径移动。 |

## 固定英雄镜头验收

1. **剪影验收**：关掉暖色局部灯，只保留月蓝轮廓；帽灯、背包、短腿和手臂仍可识别。
2. **材质验收**：以一盏琥珀前景灯和一盏冷蓝填光测试；铜、玻璃、漆面、皮革、纸张必须有不同高光和粗糙度。
3. **动作验收**：连续播放三段动画，观察是否能不依赖文字读出“看见—带回—改路”。
4. **运行时验收**：在第二章的实际相机中，Pi 不被记忆风、喷泉或UI遮挡；资产加载失败时仍允许当前安全回退，但不计为美术验收通过。

## 文件目录

```text
public/assets/production/
├── pi-hero.glb
├── pi-hero-preview-front.png
├── pi-hero-preview-side.png
├── pi-hero-preview-hero-camera.png
```

`pi-hero-manifest.json` 必须记录导出工具、三角面数、材质清单、贴图分辨率、骨骼数、动画片段名与已知限制。
