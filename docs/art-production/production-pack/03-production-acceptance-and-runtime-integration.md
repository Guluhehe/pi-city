# 第二章资产生产验收板与运行时接入计划

## 生产原则

第二章不以“资产文件已收到”作为完成，而以“资产在真实任务镜头中通过对应验收门”作为完成。每个资产进入运行时前都必须先通过独立预览；任何资产未通过时，默认玩家路径保持稳定港口，不把实验资产暴露给正式流程。

## 文件接收与技术检查顺序

| 顺序 | 责任 | 动作 | 失败条件 |
|---|---|---|---|
| A | 资产制作者 | 导出 GLB、贴图、预览图、manifest。 | 缺少贴图、节点、动画名或尺度说明。 |
| B | 集成方 | 在独立资产预览页加载，检查控制台、法线、贴图、材质与缩放。 | 外链纹理、错误朝向、破面、白模或不受光。 |
| C | 美术评审 | 以固定英雄镜头看剪影、材质、目标方向和空间层级。 | 依赖UI才能读懂；目的地不在镜头；材质混为一体。 |
| D | 玩法集成 | 在真实风筝/钥匙/电影任务中回放观察、出发、带回。 | 任务状态和资产状态不一致；动作/相机遮挡。 |
| E | 发布负责人 | 使用同设备预算进行最后检查。 | 主线性能/构建回归；未通过时关闭该资产开关。 |

## 运行时接入顺序

```text
独立GLB预览
  → 第二章美术预览（仅显式查询参数）
    → 固定英雄镜头验收
      → 真实风筝任务回放
        → 钥匙与电影任务复用
          → 第二章默认入口切换
```

### 默认路径保护规则

1. 已交付资产只在通过 A–C 后才打开第二章美术预览入口。
2. 通过 D 的风筝资产组合才允许进入章节二默认入口；钥匙和电影仍可保持原稳定场景直至各自通过 D。
3. 运行时加载失败、manifest不合格或相机验收失败时，自动保持当前稳定港口，不以低模/纯色回退伪装正式美术。
4. 每次正式切换前必须重新执行 `npm run check:ci`，并保存固定镜头和带回阶段各一张实拍验收图。
