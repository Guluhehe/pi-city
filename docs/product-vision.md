# Product Vision

## Thesis

Pi City is a watchable, explorable, increasingly controllable Agent Runtime world.

Its first job is not to teach through documentation. It lets a user watch one request move through an agent system until a correct mental model forms naturally.

## Core learning outcomes

A first-time user should understand:

1. An agent is a loop, not one model call.
2. Tool Result is evidence for another reasoning turn, not the final answer.
3. Session and Context are different objects.

## Experience ladder

1. **Watch** — follow a request automatically.
2. **Explore** — inspect World, Session, Context and Timeline.
3. **Control** — later introduce prediction, debugging and challenge mechanics.

## v0.1 product shift

Move from a hard-coded demo to **Replay a Real Pi Run**.

Entry points:

- Watch a demo
- Replay a Pi session
