# 第二至第四章城市扩展契约

**状态：** 实施前审计与扩展契约。  
**目标：** 将初版策划中第二至第四章的九件居民心愿，接入已验证的 `CityCampaign` / `CityMission` / `CityMissionStory` 基础设施，而不把城市重新变成关卡选择菜单或技术面板。

## 第一章实时 3D 审计

灯塔、邮包和喷泉均能从心愿码头进入计划、出发、到达和回流的实时 3D 链条。现有长路径试玩脚本在邮包后段出现自动化停滞，因此保留已完成的灯塔全链与邮包前段截图，不将未完成的长路径误记为运行时故障。代码审计确认共享场景的核心缺口：灯塔和邮包通过喷泉地点 id 映射获得路径，因而虽能移动，却没有任务语义化的相机基线、不同路程节奏或回流物的类别色彩。

| 审计项 | 当前情况 | 本轮精修要求 |
| --- | --- | --- |
| 计划镜头 | 有统一推进，但灯塔与邮包仍采用喷泉广场基线。 | 传递任务场景、路线目标与焦点；计划镜头先给居民对象与目标地标一个短暂停留。 |
| 出发行程 | 路线灯、Pi 移动和到达存在。 | 距离不同使用不同旅行秒数；抵达后加入短暂观察/行动停顿，不让按钮出现即跳过。 |
| 回程 | Pi 带高位发光物回到思考塔。 | 按 Fact / Detour / Confirmed / Reply 改变带回物颜色、轨迹和相机落点。 |
| 主题地标 | 灯塔、邮局有状态灯光。 | 新章节按公共目标分组，加入风筝、档案门、雨棚、夜花、风车、市场/剧场、雾灯、星光节等可读地标。 |
| 选择层 | 已从发光热点改为可观察理由。 | 章节二起引入两格小包；章节四引入先后顺序，但保留 2–3 条自然路线。 |

## 章节实现范围

| 章节 | 可玩委托 | 新增轻量规则 | 完成后的公共变化 |
| --- | --- | --- | --- |
| **第二章：Pi 会记得，也会重新想** | 找不到家的小风筝、两把钥匙、雨天的露天电影 | 小包一次带两件；玩家以两件发现的组合触发下一步，而非取得唯一正确答案。 | 屋顶风筝绳、档案小门、广场雨棚与电影灯。 |
| **第三章：Pi 会动手，也会认真收尾** | 花园里醒不过来的种子、没有署名的感谢卡、风车的秘密时间 | 行动后可选择快速回信或确认；新证据可改写初始送信路线；快/慢路线留不同明信片。 | 夜花、感谢卡展、可远望的风车与风向提示。 |
| **第四章：更多人开始相信 Pi** | 同一晚的两张心愿单、海雾里的船铃、星光节的最后一盏灯 | 选择先帮助谁；面对矛盾线索继续查；最后委托引用既有城市变化但不需要阅读技术资料。 | 市场、剧场、雾灯、船铃与完整星光节信任图。 |

每项委托均必须具备：一句儿童可理解的心愿、2–4 次地点选择、一个可选发现、一条留下物件的温和绕路、一项永久城市变化，以及一张三句以内的可选 Pi 小知识。[1]

## 城市记忆与档案馆精修契约

**信任图**应由固定三点升级为章节化的 12 枚城市印记：每个印记有居民、城市地点、完成/待办/等待三种状态，点击不会开启技术信息，只显示“这件小事让哪里变亮”。

**发现册**应从平铺列表升级为可按章节分组的物件书架。已得到、尚未遇见的空位和任务关联应并列呈现；空位只能提示城市语言，不泄露答案。

**Pi 档案馆**保留 Story / Concept / Evidence Run 的诚实边界，并增加一面“城市物件 → 已体验的 Pi 现象”墙。概念卡先按完成进度解锁，仍使用无术语句；只有主动选择真实证据入口才进入既有 Explorer。

## 验收标准

扩展完成时，根路径必须仍在 15 秒内给玩家一个可理解的下一步；12 项心愿都应通过同一纯 reducer 合法推进；每章完成后，心愿码头、信任图和发现册都出现肉眼可见的变化；所有故事状态继续标记为 `source: 'tutorial'`，不写入 `SemanticTrace`。
