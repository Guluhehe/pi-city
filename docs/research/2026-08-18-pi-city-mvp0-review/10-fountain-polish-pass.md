# 喷泉街：精致化第一轮

## 目标

当前垂直切片已证明“玩家从城市地点提出未知问题，Pi 自主调查并带回改变下一步的信息”可以在实时 3D 中成立。本轮不追求把小街区做成开放世界，而是把它从**可读的功能灰盒**升级为具有明确空间质感、镜头焦点和状态表演的**可玩的港口冒险舞台**。

视觉方向参考见 `public/assets/concepts/fountain-polish-direction.png`。该图只用于统一色彩、密度和材质目标，绝不作为运行时背景或冒充游戏截图。

## 当前画面的主要瓶颈

| 观察 | 对游戏感的影响 | 本轮处理方式 |
| --- | --- | --- |
| 大面积均匀浅色地面与纯色背景 | 城市像摆在展台上的模型，缺乏可进入的场所感。 | 用环形石板、码头木板、湿润水痕、暮色天空和远景雾化建立材质与空间层次。 |
| 地点之间的形状与价值密度相近 | 玩家能辨认方位，但难以一眼感到“这里有故事”。 | 为各地点增加独有的轮廓和微动画，例如飘动乐谱、浮标波纹、风铃、工作灯与花园灯火。 |
| Pi 的存在感只有一个移动光球 | 玩家难以把它感受为正在思考、行动、带回发现的同伴。 | 增加眼睛、微幅呼吸/漂浮、柔和光晕、提包摇摆，以及出发路径上的灯点。 |
| 结果改变主要依赖文字和手账 | “新结果改变下一步”的课程仍缺少可观看的城市反应。 | 为喷泉、风铃、水线、工具坊和花园增加逐阶段的可见材质、光照与粒子变化。 |
| 只有平铺的默认相机 | 画面没有进入、停留、出发、归来的镜头节奏。 | 调整初始构图，并在地点计划/远征/回流之间加入更明确的推进、拉回和光线聚焦。 |

## 第一轮实现范围

本轮在不新增账号、后端、开放世界或复杂角色控制的前提下，完成下列五项升级。

| 升级 | 可见结果 | 与核心玩法的关系 |
| --- | --- | --- |
| **暮色港口氛围** | 渐变天空、低位暖阳、远景雾、港口水面、暖窗与小灯。 | 把 Pi 的每次出发放进有情绪的城市，而不是展示台。 |
| **可阅读的地面与水系** | 环形喷泉石板、木栈桥/木板、波纹、纸船和湿润反光。 | 用路径、材质和水流让玩家自然理解地点之间的关系。 |
| **地点招牌动作** | 乐谱摆动、水线浮标闪烁、风铃摇摆、工具灯启闭、花园萤光。 | 调查结果能在地点上被看见，而非只写在卡片里。 |
| **Pi 伙伴表演** | 有眼神、呼吸漂浮、光晕、提包与移动灯点。 | 强化“Pi 自己去弄清”的主体感。 |
| **更像探索的提示** | 热点拥有上升光尘、呼吸环、轻微标签感与选中后的路径回应；保留自然语言备用入口。 | 玩家在城市中提出问题，但不会因错过画布命中而卡关。 |

## 明确不做

本轮不把故事模式改成自由漫游、任务清单、数值成长、多人协作或技术仪表盘。也不以生成图替换可交互 3D；最终体验仍由实时 R3F 场景承担。

## 验收标准

在一张无 UI 或轻 UI 的截图中，玩家应能立即看出这是暮色中的可进入港口小街区，而非一组方块。初看后，至少三处可调查地点应同时具有不同的轮廓与动态提示；Pi 出发、风的反证、同步阀安装和完整歌曲确认都必须让城市发生肉眼可见的变化。所有变更继续保持教学状态与 Semantic Trace 隔离。
