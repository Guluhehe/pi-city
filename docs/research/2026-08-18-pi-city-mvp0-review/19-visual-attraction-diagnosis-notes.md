# Pi City 场景吸引力：首轮画面诊断笔记

**样本：** 第2章心愿码头首屏与“雨天的露天电影”任务观察页，1280×720 实拍。

| 维度 | 当前有效之处 | 当前削弱吸引力之处 |
|---|---|---|
| 氛围 | 暮色、暖灯、低多边形建筑与海水已建立温柔、安全的港口基调。 | 大面积灰蓝天空、均质石板与近似明度的建筑让画面偏平，缺少一处能瞬间记住的“魔法事件”。 |
| 视觉焦点 | 喷泉、灯串、标题和右侧任务卡提供了阅读锚点。 | 喷泉、灯串、建筑、标题、任务卡和底部手账同时争夺注意力；没有一个角色或任务物成为不可替代的主角。 |
| Pi 的存在 | Pi 有动作、带回物和路线灯的叙事功能。 | 远景中的 Pi 尺度太小，第一眼更像一个普通小人，无法承担“这是与 Pi 一起冒险”的情绪承诺。 |
| 空间辨识 | 城市布局清楚，可支持任务切换和多地点复访。 | 建筑以同类盒状体量、相近材质与俯视镜头呈现，街区缺少强轮廓、景深层次和可进入的神秘感。 |
| 游戏感 | 心愿、发现册、小包和信任图已将玩法信息连接起来。 | UI 在首屏和任务页占据较大面积，画面更像精美的“带3D背景的互动故事页”，而不是一个正在发生的、可走进去的世界。 |

## 初步判断

问题**不是色彩不够丰富或模型数量不够多**，而是缺少明确的“视觉承诺”与“可抵达的奇观”。目前世界在告诉玩家“这是一个温暖、整理得很好看的港口”；它还没有在前五秒告诉玩家“这里有一个只有我和 Pi 能改变的奇异现象，走过去会发生事”。

可行的改造方向应优先改变构图、焦点、角色尺度、动态层次和任务对象的仪式感；不应先用更多小装饰或更重的UI来填充画面。

## 外部设计原则摘要

1. **温馨不是“所有地方都暖且亮”。** Kitfox 将温馨感归纳为安全、丰足与柔和，并强调“外部的不适”与室内/港口庇护形成对比，才能让温暖有情绪重量。[1]
2. **画面只能有明确的一层主导、少量次焦点和后退背景。** 视觉层级研究指出，强调所有元素等于没有元素被强调；单一主导元素应成为观者进入画面的入口。[2]
3. **环境需要表达因果，而不仅是摆放装饰。** Don Carson 的环境叙事讨论将可见的“发生过什么 / 接下来会发生什么”视为吸引玩家走近的空间线索，并主张只把精细装饰留给希望玩家靠近的地点。[3]

这些原则直接支持Pi City的下一步：不是把全城做得更亮、更满，而是让每一章在码头中央产生一个**可见、会呼吸、与当前心愿有关的城市奇观**；Pi 与玩家的下一步都被该奇观牵引。
