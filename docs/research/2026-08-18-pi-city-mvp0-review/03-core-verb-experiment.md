# MVP-0 核心动词对照实验：Pi 的搭档到底做什么？

## 实验目的

当前设计默认玩家在思考塔替 Pi “指下一站”。这可能带来策略感，也可能只是把玩家变成点击路线图的鼠标。MVP-0 不应把这一点当作既定事实。

本实验用同一件《半首歌喷泉》的故事与同一条动态循环，比较三种不同的玩家权力。要找的不是“功能最多”的版本，而是最能同时产生三件事的版本：玩家有理由地参与、玩家看懂结果回流、玩家愿意把 Pi 当作行动中的伙伴。

> **实验问题：** 当 Pi 遇到不完整的信息时，玩家应该替它决定去哪儿、决定它带什么回去，还是决定它还需要确认什么？

## 共同故事基线

三种版本都保留相同的事实：喷泉只唱到第七拍；观察台能发现水压在第七拍下降；码头乐手有一页缺失的回应节拍；工具坊可以做出同步阀；试演花园能确认完整旋律。Pi 的动态是相同的：初始“喷泉坏了”假设，在新事实进入思考塔后变成“水压与节拍需要同步”。

因此测试的是玩家权力，不是故事好坏、地点数量或美术质量。

## 三种候选核心动词

| 版本 | 玩家在故事中做什么 | 可见操作 | Pi 的自主性 | 主要学习假设 | 最大风险 |
|---|---|---|---|---|---|
| A：**替 Pi 指路** | 在 2–3 个可去地点中选择下一站。 | 点击观察台、码头乐手、工具坊等城市地点。 | 中等；Pi 执行玩家选择。 | 玩家能预测哪类信息会帮助 Pi。 | 退化成跟随高光或“正确地点”猜题。 |
| B：**替 Pi 整理发现** | 选择 Pi 这一次带回思考塔的两件发现物。 | 将三件实体物品放进两格邮包。Pi 根据所带材料自主前往下一处。 | 高；玩家决定 Pi 看见什么，Pi 决定怎么做。 | 玩家能看懂不同信息进入思考后会改变判断。 | 物件选择可能显得抽象，或被误解成普通背包容量。 |
| C：**替 Pi 提出确认问题** | 行动之后，选择 Pi 还必须证实哪一个疑问。 | 从“能唱完整吗？”“水流稳定吗？”“客人听得见吗？”中点一个问题。Pi 自主选择如何确认。 | 高；玩家定义成功标准，Pi 决定路线。 | 玩家能体会行动不等于已完成，验证会定义下一步。 | 只能在后半局出现，不能单独承担整局操作。 |

## 原型交互脚本

### 版本 A：替 Pi 指路

Pi 拿到“第七拍水压下降”的观察卡后回到塔内。玩家看见观察台、码头乐手、工具坊三个地点。Pi 说：“我们知道水流在第七拍有点不对，但我还不确定原因。先去哪儿好？”

玩家点码头乐手后，Pi 得到旋律页；思考塔把两张卡片并置，Pi 说：“原来缺的不只是水压，还有一段回应节拍。” 接着 Pi 自己建议同步阀工作台，或玩家继续选工具坊。

**记录问题：** 玩家是否说“我先找乐手，因为还得知道旋律”，还是“这个地方在亮”？

### 版本 B：替 Pi 整理发现

Pi 回到塔内，面前有三件可携带物：水压观察卡、旧旋律页、港口天气单。Pi 的小邮包只有两格。Pi 说：“我一次只能带两样去想下一步。哪两样最和喷泉有关？”

玩家装入水压卡和旋律页后，Pi 会自主走向同步阀工作台；若装入天气单和水压卡，Pi 先以为与风有关，去观察台补证，随后带回旋律页再重想。所有路线均可完成，但第一种更直接，第二种会产生一段“天气不是关键”的可读反证。

**记录问题：** 玩家是否说“这两张都和第七拍有关”，以及 Pi 自动改路线后，是否理解这是所带信息造成的？

### 版本 C：替 Pi 提出确认问题

Pi 已拿到同步阀回执，却准备回信。玩家看见三个轻量问题，而不是地点：“喷泉能唱完整吗？”“水流会稳定吗？”“客人听得见吗？” Pi 说：“我们改过一次了。你最想让我先确认什么？”

选择“能唱完整吗”会让 Pi 去试演花园，并得到完整旋律录音；选择“水流会稳定吗”会得到稳定水流但未验证旋律的半确认；选择“客人听得见吗”会去港口，发现喷泉仍卡在第七拍，进而自然返回花园。

**记录问题：** 玩家是否把确认理解为 Pi 完成任务的一部分，而不是又一道正确选择？

## 建议的低样本比较方式

首轮样本不够做统计显著性检验，因此不将其称作严格 A/B 测试。应以 **任务内概念比较 + 访谈证据** 方式进行：每名试玩者只完整体验一个版本的喷泉任务，避免已经学会循环后污染结果；在 6–9 名试玩者中尽可能均分 A / B / C。灯塔和邮包维持同样的最小叙事与动态状态，但不作为核心动词比较对象。

| 观察维度 | 主持人问法或观察点 | 版本胜出的信号 |
|---|---|---|
| 理由 | “你为什么刚才选这个？” | 回答引用故事事实或 Pi 当前不知道的事。 |
| 因果 | “Pi 为什么接下来换了这个做法？” | 明确提到自己选择的信息／问题与 Pi 的新判断。 |
| 主体性 | 玩家用“Pi 去看看／Pi 还不知道”还是“我点了按钮”？ | 前者更频繁，且能解释 Pi 的行动理由。 |
| 愉悦感 | 玩家是否停下来比较、预测、露出惊喜或想试另一个选项？ | 有自然的好奇和轻微反事实愿望。 |
| 负担 | 玩家是否问“这是什么意思”“我该选哪个”，或只是等待高光？ | 低困惑、低提示依赖。 |
| Pi 学习 | 完成后能否用普通语言说明“结果回来后 Pi 改了主意”？ | 不需要提示即可回答。 |

## 决策规则

不采用“谁得分最高谁赢”的伪精确结论。只有同时满足以下条件的版本，才可进入下一轮产品原型。

| 条件 | 最低证据 |
|---|---|
| 玩家理由真实 | 该版本至少 2/3 试玩者给出非“因为亮了”的理由。 |
| 动态循环正确 | 该版本至少 2/3 试玩者自发描述结果／材料／确认问题改变了 Pi 的下一步。 |
| 不依赖主持人解释 | 试玩过程中不需要解释技术词或告知正确选项。 |
| 有角色感 | 多数试玩者自然把 Pi 当作行动者，而不只描述 UI。 |
| 没有系统性误教 | 没有多名玩家将 Pi 理解成“按固定楼层顺序走”的角色。 |

若 A、B、C 都不能同时满足，不应选“相对不差”的版本继续美化。团队应回到更根本的问题：玩家也许不该替 Pi 做决策，而应通过观察、提问、比较或安排实体发现，以另一种方式参与 Pi 的判断。

## 不应从实验中得出的结论

- 若 B 获胜，不等于 Pi 的真实 Context 就是固定两格背包；它只说明“选择 Pi 此刻看见什么”更容易被玩家理解。
- 若 C 获胜，不等于所有任务都应以确认问题结束；它只说明“定义完成标准”可能比“指路”更有参与感。
- 若 A 获胜，不等于以后每个地点都需要玩家点选；它只说明空间路线在当前故事中足够自然。
- 若玩家偏好某版本的美术或角色对白，不得将其误当成核心动词的胜利；三版视觉与叙事必须尽量一致。
