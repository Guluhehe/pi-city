# 记忆风街角：运行时实施记录

## 已落实的运行时基础设施

本次实施没有继续将概念图压缩为“默认港口上的更多光球”。第二章现已拥有一个隔离的 `MemoryWindStreetCorner` 环境入口，其组成包括湿石地面、窄屋模块、坡屋顶、窗户、红门与台阶、码头边缘、前景铜灯、绳索和局部剧情补光。`FountainStoryScene` 以 `streetCorner` 为显式开关，只有预览路径 `?story=2&artPrototype=memory-wind` 才会启用它；默认玩家入口继续使用已验证的稳定港口。

夜景管线也被切分为街角专用分支：深蓝天空、近景雾、降低的环境曝光、有限的冷填光，以及分别服务前景灯、红门和记忆风的暖色实用光。旧任务地标、通用建筑和大面积广场在该预览分支被隔离，避免它们重新抢夺镜头主角。

同时，新建 `memory-wind-assets.ts` 把Pi、红门、前景灯和记忆风套件定义为正式GLB交接槽位。Pi运行时适配层会尝试加载 `pi-hero.glb`；如果资产含有名为 `idle-observe`、`take-note`、`turn-and-trot` 的动画片段，则按记忆风的“看见—挑页—改路”节拍自动混合播放。资产不存在或加载失败时，程序化Pi安全回退，既有任务状态机不会受影响。

## 当前验收结论

| 项目 | 状态 | 结论 |
|---|---|---|
| 模块化街角接口 | 完成 | 已可独立替换第二章环境，并成为后续正式GLB装配点。 |
| 夜景、暖光与镜头分支 | 完成 | 已独立于默认港口，避免正式玩家体验被未成熟的Lookdev覆盖。 |
| Pi正式资产适配 | 完成 | GLB、骨架动画和回退路径均已有运行时接口。 |
| 默认12任务稳定性 | 通过 | `npm run check:ci`：64/64测试、类型检查、生产构建均通过。 |
| 电影化最终画面 | 未通过正式美术验收 | 程序化模块仍不能替代纹理化GLB、真正的材质包与角色骨骼资产；预览路径因此保持隔离。 |

## 下一次切换默认入口的硬门槛

只有在交接包中的Pi GLB、红门窄屋、前景灯与记忆风资产到位，且街角在真实浏览器镜头下通过“Pi—未知问题—目的地”三层可读性审核后，`streetCorner` 才可设为默认。这样可防止功能层面的进展被误判成正式美术完成。
