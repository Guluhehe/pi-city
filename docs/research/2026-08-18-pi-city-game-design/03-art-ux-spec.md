# Pi City 美术与交互体验规格 v0.1

## 一、创作方向：不是儿童化，也不是技术面板

Pi City 应保留现有作品最独特的部分：**港口、档案、车间、闸门、货物与运行中的城市**。这些不只是装饰，而是 Pi 把请求、记忆、行动和结果变成可见事物的核心隐喻。[1] 新的轻量入口不是推翻这座工业港，而是在它的前景加上一层可亲近的居民生活与 Pi 的小旅行。技术结构仍然是真实的城市骨架；非技术玩家先认识它们为有故事的地点，之后才自愿认识其 Pi 含义。

> **视觉承诺：** 一眼看去，这是一个黄昏时分、正在替居民办事的海港小城；看久一点，才发现每一件小事背后都在表达 Pi 的运行逻辑。

风格应是“有温度的功能性港口”，而非糖果色儿童城、赛博控制室或办公软件拟物化。参考 A Short Hike 的清楚地标与可探索尺度、TOEM 的单一交互可读性、Alba 的温暖街区生命感，只吸收其设计逻辑，不复制其角色、构图或资产。[2] [3] [4]

## 二、视觉支柱

| 支柱 | 必须看见的结果 | 应避免的误区 |
|---|---|---|
| **城市先于图表** | 建筑、路、车、灯、码头先传达状态；文本只作补充。 | 把游戏做成换皮流程图或仪表板。 |
| **每个 Pi 行为都有住所** | 玩家能记住“要看看去观察台、带回发现回思考塔”。 | 用一排抽象按钮代替空间。 |
| **信息是可携带的物品** | 信封、照片、回执、徽章、萤火印章有稳定形状和去向。 | 让信息只以浮窗、长文本、日志流存在。 |
| **因果是会动的** | Pi 出发、带回、塔内变化、地点点亮形成完整可见链。 | 点击后只弹一句说明。 |
| **温柔但不幼稚** | 有风、灯、机械、纸张、玻璃与居民细节；色彩克制、局部温暖。 | 过度可爱化、表情包化，或黑客电影式紧张感。 |
| **证据与故事不混淆** | 教学故事和真实 Trace 都有不同的视觉容器与清楚标签。 | 把作者场景伪装成真实 Pi 记录。 |

## 三、世界的双层美术：港口骨架与居民表情

现有世界中的 Arrival Harbor、Archive / Context Works、Model Core 与 Tool workshops 是 Pi City 的结构资产，应继续承担“请求进入、历史沉淀、决策产生、工具执行”的空间角色。[1] 轻量任务层不新增一套卡通世界，而是在这些地点附近增加可读、少量、可反复组合的居民表情层。

| 世界层 | 视觉语言 | 玩家先理解的意思 | Pi 的后层含义 |
|---|---|---|---|
| 港口骨架 | 风化金属、玻璃、运输轨道、货物、低矮建筑、雾灯。 | 一座会运转、会接收委托的海港。 | Agent 运行的物理隐喻。 |
| 居民表情 | 手写招牌、纸船、晾晒照片、花盆、小摊、窗灯、角色小动作。 | 这里真的有人等待 Pi 帮忙。 | 请求的具体目标与用户世界。 |
| Pi 路线 | 低矮发光小车／信使胶囊、细光轨、停靠动作。 | Pi 正在替我跑一趟。 | 一次 Agent 行动与结果回流。 |
| 发现物 | 一致剪影的信封、相册页、观察卡、车间回执、萤火印章。 | Pi 发现或带回了重要东西。 | Request、Memory、Observation、Tool Result、Verify。 |
| 后台档案 | 深色但干净的纸质档案、标尺、时间线、可展开证据。 | 想更懂 Pi 的人可以去的后台。 | Trace Explorer 与 evidence levels。 |

## 四、角色与物件规格

### Pi：一个让玩家愿意陪着跑的“城市助手”

Pi 的形象应优先支持动作、停顿与状态切换，而非依赖复杂表情。建议采用 **圆角金属信使胶囊 + 小型望远镜式观察头 + 可开合的邮包舱** 的组合。它的剪影必须在远景中也能认出：偏圆的主体、前方小光眼／观察镜、背后或侧面的邮包盖、底部小轮或悬浮轨道。它不需要开口说很多话；一两次看向发现物、犹豫、兴奋地带回徽章，就足以形成性格。

| Pi 状态 | 角色动作 | 玩家应读到的意思 | 声音方向 |
|---|---|---|---|
| 待命 | 在思考塔前整理邮包、轻微摇晃。 | 等待下一趟帮助。 | 低频机械呼吸、纸张轻响。 |
| 被指路 | 观察镜对准地点，短促点头。 | “我知道该去哪儿了。” | 清亮确认音。 |
| 观察 | 伸出观察镜或放大卡片。 | 正在弄清楚发生了什么。 | 微小聚焦音。 |
| 行动 | 邮包舱打开、工具标志亮起。 | 正在做一件真正的事。 | 柔和机械节奏。 |
| 带回 | 发现物悬浮或被放入包舱。 | 有新东西要交给思考塔。 | 两段式收纳音。 |
| 确认 | 灯光稳定、转向玩家或居民。 | 现在可以有把握地回信。 | 温暖和弦／风铃。 |
| 温和绕路 | 小停顿、挠头式机械摆动，立刻指向下一处。 | 还差一点，但不是失败。 | 轻巧的未完成音，不使用警报。 |

### 六类发现物：看见形状，就知道它在故事里扮演的角色

| 发现物 | 轮廓与材质 | 核心色 | 它从哪来、去哪 | 避免 |
|---|---|---|---|---|
| 心愿信封 | 三角封口、毛边纸张、手写蜡印。 | 暖米白 + 珊瑚红。 | 居民 → 思考塔。 | 变成普通任务图标。 |
| 记忆相册页 | 拍立得边框、折角、褪色照片。 | 鼠尾草绿 + 旧纸黄。 | 图书馆 → 邮包／思考塔。 | 做成数据库方块。 |
| 观察卡 | 透明玻璃片、被圈出的细节、望远镜纹样。 | 海雾蓝。 | 观察台 → 思考塔。 | 长篇文字报告。 |
| 工具回执 | 金属小票、齿轮压纹、已完成戳记。 | 铜橙。 | 工具坊 → 思考塔。 | 扳手本体或代码符号。 |
| 确认印章 | 发光萤火／星形印记、小小时间环。 | 金色 + 青绿。 | 花园／现场 → 回信码头。 | 绿色对勾。 |
| 感谢纸船 | 折纸小船、居民名字与小旗。 | 纸白 + 任务主题色。 | 回信码头 → 城市水面。 | 分数券或金币。 |

## 五、地点与状态颜色

颜色必须服务“现在 Pi 在做什么”，而不是把整个城市涂成彩虹。世界底色保持暮蓝、海雾灰、风化铜和旧纸黄；只在发生行动的地点与发现物上出现饱和高光。这样即使玩家不读字，也能从全城中看出当前焦点。

| 地点 | 主色与材质 | 空闲状态 | 被选中状态 | 成功后变化 |
|---|---|---|---|---|
| 心愿码头 | 珊瑚红、木板、纸旗。 | 一盏微亮码头灯。 | 信封边缘暖光、纸船轻摇。 | 居民窗户多一盏光。 |
| 旧日图书馆 | 鼠尾草绿、木材、玻璃书架。 | 少量漂浮纸页。 | 一页相册轻展开。 | 墙面多一张任务照片。 |
| 观察台 | 海雾蓝、玻璃、望远镜。 | 光束扫过港口。 | 镜片聚焦、远处细节被圈亮。 | 观景台出现可收藏的远景照。 |
| 工具坊 | 铜橙、磨砂金属、机械臂。 | 小齿轮缓慢转动。 | 工具门打开、火花与回执生成。 | 门口出现本任务修好的小物。 |
| 暮色花园 | 青绿、夜花、半透明玻璃。 | 萤火缓慢漂浮。 | 时间环收拢、萤火聚集。 | 新花在之后夜晚持续开放。 |
| 回信码头 | 米白、深蓝水面、纸船。 | 一只纸船漂着。 | 纸船折起、驶向居民。 | 水面留下一条微光航线。 |

## 六、镜头与交互：一次任务只需要一个清楚的下一步

默认镜头为 **斜 3/4 俯视、近景可读、远景可感知全城变化**。玩家不用学习第一人称移动、自由相机或复杂缩放。镜头只做三件事：展示 Pi 回到思考塔、轻推到可选地点、在关键因果发生时给一个短特写，然后回到城市总览。

| 时机 | 镜头行为 | 可交互内容 | UI 规则 |
|---|---|---|---|
| 心愿抵达 | 从港口稍拉近到居民与 Pi。 | 点击“帮忙看看”。 | 不出现任务列表；一句居民愿望足够。 |
| Pi 在思考 | 回到中央总览，2–3 个地点出现柔光呼吸。 | 点击一个地点。 | 地点名是动词短句，如“先去看看”。 |
| Pi 在路上 | 沿路线平移 2–4 秒。 | 无需点击。 | 不弹说明；用路线、声音和景物讲过程。 |
| 发现产生 | 轻推到物件与 Pi 的邮包。 | 点击继续带回。 | 不用遮屏弹窗。 |
| 结果回流 | 思考塔内出现新发现物，旧物件围出短暂关联。 | 再次选择地点。 | 新解锁地点优先亮起；不写技术名词。 |
| 任务完成 | 扩展到居民与街区变化。 | 点击纸船／继续探索。 | 先让玩家看城市，再展示可跳过复盘卡。 |

**交互原则：** 玩家在任何时刻最多只面对一个主操作。没有超过三个同时发亮的地点；没有图标堆叠；没有“正确答案”外观。若某个地点暂时不可去，呈现为自然的城市原因，例如工具坊门没开、图书馆还没有可查的相册，而不是灰色锁头。

## 七、教学故事与真实 Trace 的视觉分界

教学任务是作者定义的故事，需要以专属容器显示：任务开场左上角有小纸旗“Pi 的城市故事”，结尾可点击“看看 Pi 的后台档案”。真实导入的 Pi 运行则继续使用现有 Observed / Derived / Synthetic 证据模型与 Explorer 视觉语言。[1] 两者可使用同一座港口和同一套地点隐喻，但不能共享同一种证据标签、时间线容器或“这是历史”的暗示。

| 模式 | 主视觉容器 | 默认信息密度 | 信息标示 |
|---|---|---|---|
| 城市故事 | 温暖的居民纸旗、发现物、路线与地点。 | 低。 | 仅故事目标与可选复盘。 |
| Pi 小知识 | 纸质明信片翻面、城市物件对照。 | 中。 | 说明“在 Pi 里这叫……”。 |
| 后台档案馆 | 深色档案纸、时间线、来源标记、可展开证据。 | 高。 | Observed / Derived / Synthetic 明确可见。 |

## 八、原型美术优先级

在高保真资产前，先用统一色块、轮廓、假物件与简易路线完成验证。正式资产只在玩家能理解和喜欢核心循环后生产。

| 优先级 | 需要制作／验证的视觉 | 验收问题 |
|---:|---|---|
| P0 | 思考塔、6 地点轮廓、Pi 剪影、发光路线、6 类发现物。 | 不读字时，玩家知道 Pi 在哪里、带回了什么吗？ |
| P1 | Pi 的 7 个状态、两位居民、昼夜／地点成功变化。 | 玩家能读出“还差一点”与“真的办好了”的区别吗？ |
| P2 | 细节材质、街区小物、远景港口、可选发现的演出。 | 玩家会不会因为城市本身想多停留或重玩？ |
| P3 | 高级镜头、角色丰富动作、季节／天气、后台档案美术。 | 核心循环已通过试玩后才考虑。 |
