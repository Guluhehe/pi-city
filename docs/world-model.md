# World Model

Pi City uses five ontology primitives:

- **Place** — where something happens.
- **Artifact** — an information object.
- **Process** — a transformation.
- **State** — current runtime values.
- **Signal** — lifecycle events.

## Core city institutions

- Arrival Terminal — external request intake.
- Session Archive — durable history.
- Context Works — select and assemble the current model-visible context.
- Model Core — inference and next-action choice.
- Tool District — external actions such as read/edit/bash/write.
- Compression Plant — future compaction mechanic.
- Timeline Junction — future branch/tree mechanic.
- Resource Docks — future skills/resources/extensions.

## Visual grammar

- User Message -> request vessel / commission crate
- Session Entry -> archive record
- Context -> assembled dossier / capsule
- Tool Call -> work order
- Tool Result -> returned report / archive case
- Assistant Answer -> final dispatch

The default world should not use permanent glowing data pipes. Diagnostic overlays are opt-in.
